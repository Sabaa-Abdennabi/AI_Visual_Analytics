# 🔎 AI Visual Analytics

**In an age where user attention is fleeting, understanding behavior is key to designing effective digital experiences.**

This insight led our team — **Sabaa Abdennabi**, **Jihen Mkhinini**, and **Arij Thabet ** — to develop **AI Visual Analytics**, our end-of-year software engineering project. It bridges the gap between user behavior and data‑driven design.

The project was made possible through the invaluable guidance of **Dr. Hajer Taktak**, whose mentorship shaped every stage of our work.

---

## 🧠 What is AI Visual Analytics?

**AI Visual Analytics** is a smart tool that tracks and analyzes how users interact with any website — from **scrolling** and **clicking** to **time spent on each section** — then turns that raw data into actionable design insights.

By combining:
- **Web scraping**
- **Machine learning**
- **Heatmap visualization**
- **Large Language Model (LLM)-based UX feedback**

...we help designers and developers understand what users care about and how to optimize interfaces accordingly.

---

## 🔍 Key Features

- **🌐 Web-Based Input** — Submit any website URL for analysis  
- **🤖 Machine Learning Analysis** — Predict zones of user interest  
- **🔥 Dynamic Heatmap Generation** — Visualize attention across page sections  
- **🧾 LLM-Powered UX Suggestions** — Get natural-language feedback to improve UI/UX  

---

## ⚙️ End-to-End Pipeline

1. **Frontend Dashboard** — User submits a URL
2. **Backend Orchestrator** — Manages and sequences all components
3. **Web Scraper** — Extracts the structure and content of the target site
4. **ML Model** — Predicts user focus areas using behavioral patterns
5. **Heatmap Generator** — Builds a visual attention map
6. **LLM Module** — Suggests UX improvements in human-readable form
